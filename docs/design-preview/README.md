# Mobile design previews

Captured from the actual Compose screens using Robolectric native Android 34 graphics (412 × 895). Production artwork comes from the current TMDB trending catalog, filtered for the active profile. These deterministic tests use TMDB poster/title-logo fixtures and extract the footer/background colors from the actual image. The image fixtures are test resources and are excluded from the APK. These previews do not establish emulator startup or physical-device performance.
