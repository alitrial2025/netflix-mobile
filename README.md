# Netflix Pro for Android phones

Kotlin and Jetpack Compose Android project. Application code and bundled assets are in app/src; Gradle configuration and wrappers are at the project root.

Open this folder in Android Studio when preparing your own build. Runtime configuration uses the existing Gradle/BuildConfig and Firebase configuration. This app and D:\Netflixtv use the existing shared Firebase project for account and profile data.

The Android app does not require a Node runtime. The loose Node session diagnostic was archived during workspace cleanup on 2026-09-29.
